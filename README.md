# PinMate
Vladyslav Bondarenko

**PinMate** is an Android application designed for Israelis planning long-term journeys to build itineraries and find travel companions.

## Features
- **Splash Screen:** App launch screen.
- **Sign Up & Log In:** Secure user authentication, input validation, age/gender selection, and data transfer via `Intent`.
